You will need to run the following commands to use Pyinsect 

First You MUST install PyTorch

Linux : pip install torch --break-system-packages 

Windows & macOS : pip install torch

(Python is required)

Then you will need to install PyTorch Vision

Linux : pip install torch torchvision --break-system-packages 

Windows & macOS : pip install torch torchvision



Then to use it you will need to run Pyinsect_installer which will take about 40 minutes to 1 hour depending on WiFi speed.

After that you will run train which will train you model (Or you can use the one included).

Then you will run Pyinsect model executor which will be used to use the model.

To use Pyinsect model executor first i will show all models that are it the folder its in (It does not read from sub folders).

Then after you select your model you will have to enter the path to the PNG file of the insect and it will say what insect it is(Please note that this is a early development stage for the model so it will 

not be very accurate).
