Pyinsect
Photo kit for GitHub Pages

For people who have never coded

Install insect pictures, then download a zip the trainer understands.

Drop photos here. This page packs them into data/train and data/val folders. GitHub Pages cannot store files on a server, so you download a zip to keep them.

How to install photos

  1. Collect close-up pictures of one insect. Not trees. Not people.
  2. Type the everyday name, like japanese beetle.
  3. Drop the pictures in the box. Repeat for other insects.
  4. Click Download. Unzip the file. You now have a data folder.

Why not the normal iNaturalist API

The public API is a doorbell. You only get about 10,000 rings per day. Downloading hundreds of pictures per insect rings it until the site says the request is too big, or blocks you. Use the API only for names. Pull the actual pictures from the AWS open-data photos, or gather them by hand.

Do not use only this source

One website teaches the bot that website’s style. Mix sources:

  • iNaturalist AWS open photos
  • USDA / Forest Service pest pages
  • BugGuide
  • University extension fact sheets
  • Your own photos

If a shot is junk, delete it. Bad photos train a bad bot.
